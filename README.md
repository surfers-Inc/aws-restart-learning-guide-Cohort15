### 🌊 Core Purpose & Mission

This repository serves as our shared knowledge base and practical portfolio throughout our AWS re/Start journey[cite: 1]. It is designed to answer three simple questions:
1. **What did we learn?**
2. **What did we actually practice?**
3. **What can we now build or troubleshoot?**

Our goal is not to copy classroom slides, but to condense concepts, track hands-on evidence, and prepare for our certification exams and technical interviews.

| Folder | What Goes Inside? |

---

### 🚀 How to Contribute

1. **Claim a Topic:** Check existing Issues or open a new one before writing[cite: 2].
2. **Create a Branch:** Use standard naming like `feat/notes-networking` or `labs/vpc-setup`.
3. **Follow the Template:** Use the note/lab templates found in `docs/`.
4. **Sanitize Everything:** Check all screenshots and logs for AWS Account IDs, Access Keys, or emails.
5. **Open a PR:** Submit a Pull Request targeting the `main` branch using our PR checklist.
